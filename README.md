# Онлайн-тестирование

Простое и надёжное веб-приложение для прохождения тестов. Пользователь вводит
имя, отвечает на вопросы (с вариантами или открытые), видит свой результат, а
полный отчёт автоматически приходит владельцу в **Telegram**.

Стек: **React + TypeScript + Tailwind CSS + Vite**, backend — serverless-функция
на **Vercel**.

## Запуск локально

Нужно, чтобы был установлен [Node.js](https://nodejs.org/) (версия 18 или новее).

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Запустите сайт для разработки:

   ```bash
   npm run dev
   ```

   Откройте адрес, который покажет терминал (обычно `http://localhost:5173`).

> **Важно про Telegram при локальном запуске.**
> Команда `npm run dev` запускает только сайт, но **не** backend-функцию
> `/api/telegram-result`. Поэтому при обычном локальном запуске отправка в
> Telegram работать не будет (сайт покажет «Не удалось отправить результат» —
> это нормально). Чтобы проверить отправку локально, установите Vercel CLI и
> запустите проект через него:
>
> ```bash
> npm install -g vercel
> vercel dev
> ```
>
> В этом режиме работают и сайт, и функция. Токен возьмётся из файла `.env`
> (см. ниже). На боевом сайте (после деплоя на Vercel) отправка работает всегда.

## Настройка Telegram

Чтобы результаты приходили вам в Telegram, нужны две вещи: **токен бота** и ваш
**chat_id**.

### 1. Создать бота и получить BOT TOKEN

1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Придумайте имя бота и его username (должен заканчиваться на `bot`).
4. BotFather пришлёт **токен** вида:

   ```
   123456789:AAExampleTokenHereReplaceItAAAA
   ```

   Это и есть `TELEGRAM_BOT_TOKEN`. **Никому не показывайте его.**

### 2. Получить CHAT ID (ваш личный ID)

1. Откройте своего нового бота в Telegram и нажмите **Start** (или напишите
   ему любое сообщение, например «привет»). Это обязательный шаг — без него
   бот не сможет вам писать.
2. Узнайте свой chat_id одним из способов:
   - **Простой способ:** напишите боту [@userinfobot](https://t.me/userinfobot) —
     он пришлёт ваш `Id` (это число и есть chat_id).
   - **Ручной способ:** откройте в браузере адрес (подставив свой токен):

     ```
     https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
     ```

     Найдите в ответе `"chat":{"id":123456789,...}` — число `id` это и есть
     `TELEGRAM_CHAT_ID`.

> Хотите получать результаты в группу? Добавьте бота в группу, напишите там
> сообщение и возьмите `id` группы из `getUpdates` (у групп он отрицательный).

## Переменные окружения

Приложению нужны две переменные:

| Переменная            | Что это                                   |
| --------------------- | ----------------------------------------- |
| `TELEGRAM_BOT_TOKEN`  | Токен бота от @BotFather                   |
| `TELEGRAM_CHAT_ID`    | Ваш chat_id (куда присылать результаты)    |

### Локально

Создайте файл `.env` в корне проекта (можно скопировать из `.env.example`) и
впишите значения:

```
TELEGRAM_BOT_TOKEN=123456789:AAExampleTokenHere
TELEGRAM_CHAT_ID=123456789
```

Файл `.env` **не** попадёт в GitHub — так и должно быть (он в `.gitignore`).

### На Vercel

В настройках проекта: **Settings → Environment Variables** добавьте те же две
переменные (`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`) и нажмите **Save**. После
этого сделайте **Redeploy** (переразвернуть проект), чтобы значения применились.

> ⚠️ Токен нельзя писать во фронтенд-код и нельзя коммитить в GitHub. Он живёт
> только в переменных окружения. В этом проекте токен используется исключительно
> в серверной функции `api/telegram-result.ts`.

## Добавление и редактирование вопросов

Все вопросы находятся в одном файле:

```
src/data/questions.ts
```

Там же, в самом верху, можно поменять **название теста** (`TEST_TITLE`).

### Пример вопроса с вариантами ответа

```ts
{
  id: 1,
  type: 'choice',
  question: 'Какой город является столицей России?',
  options: ['Санкт-Петербург', 'Москва', 'Казань', 'Новосибирск'],
  correctAnswer: 'Москва', // правильный вариант — точно как в options
},
```

### Пример вопроса с открытым ответом

```ts
{
  id: 2,
  type: 'text',
  question: 'Напишите название самой большой планеты Солнечной системы.',
  correctAnswers: ['юпитер'], // можно несколько допустимых вариантов
},
```

Проверка открытых ответов «умная»: не важен регистр букв, лишние пробелы по краям
и двойные пробелы внутри, а «ё» приравнивается к «е». Например, все варианты
`Абу Ханифа`, `абу ханифа`, ` Абу Ханифа ` считаются одинаковыми. Если возможны
разные написания — просто добавьте их все в массив `correctAnswers`:

```ts
correctAnswers: ['абу ханифа', 'имам абу ханифа', 'ханифа'],
```

**Как добавить новый вопрос:** скопируйте любой блок `{ ... }`, вставьте его в
список и поменяйте текст. У каждого вопроса `id` должен быть уникальным. Не
забудьте запятую после закрывающей `}`.

## Публикация в интернете (Deployment)

Самый простой способ — **Vercel** (бесплатно).

1. Загрузите проект в репозиторий на [GitHub](https://github.com) (файл `.env`
   при этом не загрузится — это правильно).
2. Зайдите на [vercel.com](https://vercel.com), войдите через GitHub.
3. Нажмите **Add New → Project**, выберите ваш репозиторий, нажмите **Import**.
4. Vercel сам определит настройки (Framework: Vite). Ничего менять не нужно.
5. Перед деплоем откройте **Environment Variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
6. Нажмите **Deploy** и дождитесь окончания.
7. Готово! Vercel даст ссылку вида `https://ваш-проект.vercel.app` — это и есть
   ваш работающий сайт. Функция `/api/telegram-result` заработает автоматически.

> Если вы добавили переменные окружения уже после деплоя — зайдите во вкладку
> **Deployments**, откройте последний деплой и нажмите **Redeploy**.
